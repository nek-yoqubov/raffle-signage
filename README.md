# PROMEBEL — Табло розыгрыша (SignageOS / группы)

Вертикальный экран **9:16** для шоурума. Светлая тема (шапка светлая — под
прозрачный чёрный PNG-логотип). Живой список участников, призы появляются
поверх списка как колода карт (каждая карточка ложится сверху предыдущей),
условия печатаются по буквам.

## Файлы

| Файл | Что это |
|------|---------|
| `raffle_signage.html` | Сама страница-табло |
| `raffle_script.gs` | Бэкенд для Google Sheets (отдаёт JSON) |

## Что нужно положить рядом с `raffle_signage.html`

Страница подставляет реальные фото и логотип по относительным путям. Положи в ту же папку:

| Имя файла | Содержимое |
|-----------|------------|
| `logo_promebel.png` | Логотип PROMEBEL (прозрачный PNG) |
| `prize_labo.jpg` | Фото автомобиля **LABO** (Приз 1) |
| `prize_stanok.jpg` | Фото **кромочного станка** (Приз 2) |
| `prize_vietnam.jpg` | Фото **путёвки / Вьетнам** (Приз 3) |

> Если какого-то файла нет — страница не ломается: вместо фото показывается
> аккуратная подпись с названием приза (без эмодзи). Как только положишь файл —
> появится реальное фото. Формат фото любой (`.jpg`/`.png`/`.webp`), под карточку
> лучше вертикальные или квадратные снимки.

## Подключение данных (Google Sheets)

1. Создай таблицу, лист назови **`Участники`**, два столбца:
   ```
   A: Контрагент            B: Сумма
   Каюмов Рустам Истаравшан  167024.85
   ...
   ```
   Вставляешь экспорт из 1С как есть — пробелы и запятые в числах бэкенд разберёт сам.
2. `Расширения → Apps Script` → вставь `raffle_script.gs` → замени `ВСТАВЬ_ID_ТАБЛИЦЫ`
   на ID из URL таблицы (`/spreadsheets/d/`**`ВОТ_ЭТО`**`/edit`).
3. `Развернуть → Новое развёртывание → Тип: Веб-приложение → Доступ: Все` → скопируй URL.
4. В `raffle_signage.html` вставь этот URL в строку:
   ```js
   const API_URL = "…";
   ```

Пока данные не подключены — табло показывает демо-список реальных контрагентов,
чтобы сразу было видно, как всё выглядит.

## Механика купонов

- `50 000 сом` покупок = **1 купон**
- каждые следующие `10 000 сом` = **+1 купон**
- суммы копятся несколько месяцев

Расчёт купонов делается автоматически из суммы — вручную считать не нужно.

## Показ на экранах и в группах

- **SignageOS** — добавь URL страницы как веб-слайд, интервал обновления любой
  (страница сама перезагружает данные каждые 60 сек).
- **Telegram / WhatsApp** — просто скинь ту же ссылку в группу.
